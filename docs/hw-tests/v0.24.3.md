# v0.24.3: DCS receive and transmit

FM channels with a DCS code send and detect it: the transceiver gets the
23-bit DCS word in its own bit order, both tone generators run on the
134.4 Hz bit clock, and receive switches on the second tone detector
and the tone output selection along with the normal or inverted DCS
detector. While a DCS code is received, the tone detector's match and
unmatch thresholds are 8 and 7; CTCSS and no-tone channels get back the
thresholds the transceiver had after start-up.

Needs a second FM radio that can send and receive DCS, and a codeplug
with FM simplex channels on one frequency: DCS 023N both ways, DCS 023I
both ways, DCS 754I both ways, TX CTCSS 88.5 Hz with RX DCS 023N, TX DCS
023N with RX CTCSS 88.5 Hz, and CTCSS 88.5 Hz both ways. Squelch mode
CTCSS/DCS on all of them unless a step says otherwise.

## Steps

| # | Do | Expect |
| --- | --- | --- |
| 1 | Flash; on the CTCSS channel `fm 5b` | "DeltaMM 0.24.3"; note the value (the start-up thresholds) |
| 2 | DCS 023N channel: `fm 4b`, `fm 4c`, `fm 3a`, `fm 5b` | `0064`, `0e37`, low six bits `2a`, `0807` |
| 3 | DCS 023N: transmit to the other radio set to DCS 023N, then to 025N | Heard on 023N; the other radio stays closed on 025N |
| 4 | DCS 023N: the other radio sends DCS 023N, then 023I, then 025N, then no tone; `fm status` during each | Speaker opens on 023N only; `tone heard` then, `tone not heard` for the others |
| 5 | DCS 023N: the other radio talks for 30 s on 023N | Audio stays open the whole time, no drop-outs |
| 6 | DCS 023I channel: `fm 3a`; the other radio sends 023I, then 023N | Low six bits `2c`; opens on 023I only |
| 7 | DCS 023I: transmit to the other radio set to 023I, then 023N | Heard on 023I only |
| 8 | DCS 754I channel: `fm 4b`, `fm 4c`; receive and transmit 754I with the other radio | `001b`, `cf82`; heard both ways |
| 9 | TX CTCSS 88.5 / RX DCS 023N channel: the other radio sends DCS 023N, then receives on CTCSS 88.5 Hz | Opens on 023N; the other radio hears the transmission on 88.5 Hz |
| 10 | TX DCS 023N / RX CTCSS 88.5 channel: the other radio sends CTCSS 88.5 Hz, then receives on DCS 023N | Opens on 88.5 Hz; the other radio hears the transmission on 023N |
| 11 | Back on the CTCSS channel: `fm 5b`; receive and transmit 88.5 Hz | The value from step 1; CTCSS works both ways as before |
| 12 | DCS 023N channel with squelch mode carrier (SQ in the codeplug); the other radio sends 025N | Speaker opens on the carrier |

## Results

Run 2026-11-06 on a D878UVII PLUS (transceiver N version) with 0.24.3
alone, indoors, the radio's own antenna, USB to a laptop for the log,
and a second FM radio with DCS. The tones were set from the console
(`fm rx`, `fm tx`, `fm tone rx|tx`) on a 70 cm simplex frequency,
12.5 kHz, low power, in place of codeplug channels.

| # | Result |
| --- | --- |
| 1 | Pass: `DeltaMM 0.24.3`; `fm 5b` = `0507` with no tone |
| 2 | Pass: `0064`, `0e37`, `40ea`, `0807`; `0x4A` and `0x4D` read back other values than the 134.4 Hz written, as they do for CTCSS |
| 3 | Pass: heard on 023N; the other radio stayed closed on 025N |
| 4 | Pass: opened on 023N only; closed on 023I, 025N and no tone. With no signal, 20 reads of `fm 1c` over 10 s never showed a DCS match |
| 5 | Pass: the squelch opened once and stayed open for the whole 38 s talk, closing when the other radio stopped |
| 6 | Pass: `40ec`; opened on 023I only |
| 7 | Pass: heard on 023I only |
| 8 | Pass: `001b`, `cf82`; heard both ways |
| 9 | Pass |
| 10 | Pass |
| 11 | Pass: `0507` again; 88.5 Hz received after the DCS steps, and sent in step 9 |
| 12 | Not run |

With DCS 023N set and the other radio sending 025N, the green LED lit
for the carrier while the speaker stayed closed.
