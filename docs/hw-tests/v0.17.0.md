# v0.17.0: battery save and backlight time

The backlight goes off after the codeplug's light time. Five seconds
after that, with no key, signal or transmission, battery save starts:
the receiver sleeps 150 ms (70 ms with Fast wake) and listens 180 ms, in
turn. A key, the knob, a signal or PTT ends it at once. Settings come
from the codeplug and can be changed for the session in the menu
(Display: Light time; Battery: Battery save) or on the console
(`light time <s>`, `save 0-2`; `save` alone shows the state).

The channel knob now moves one channel per click.

## Before you start

- A codeplug with battery save on and a light time other than Always.
- An FM channel with a signal you can trigger, such as a repeater.
- The log port open, to follow the `power:` lines.

## Steps

| # | Do | Expect |
| --- | --- | --- |
| 1 | Flash; watch the start screen and the log | "DeltaMM 0.17.0"; log `power: battery save on, 150 ms sleep` (or the codeplug's setting) |
| 2 | Menu: Display, then Battery | Light time and Battery save show the codeplug's values |
| 3 | Leave the radio alone for the light time | The backlight goes off |
| 4 | Wait 5 s more | Log `power: battery save: receiver sleeps 150 ms, listens 180 ms` |
| 5 | Console `save` | `receiver asleep` or `listening`, the sleep count rising, awake for: nothing |
| 6 | Press a key | Backlight on; log `battery save ended`; the key does its job |
| 7 | Let battery save start again, then trigger a signal on the channel | The squelch opens within a fraction of a second; audio is heard; the backlight comes on |
| 8 | Let battery save start again, then press PTT | Transmits at once; releasing returns to receive |
| 9 | Menu: Battery save Off, then leave the radio | The backlight goes off; no battery save |
| 10 | Menu: Battery save Fast wake | Battery save starts with `sleeps 70 ms` |
| 11 | Menu: Light time Always | The backlight stays on; no battery save |
| 12 | Console `fm status` while battery save runs | The receiver answers; battery save starts again after 5 s idle |
| 13 | Turn the channel knob one click at a time, both ways | Each click moves one channel |
